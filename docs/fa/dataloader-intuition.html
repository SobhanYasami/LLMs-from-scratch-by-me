تکمیلی: دیتالودر با اعداد ساده

تکمیلی

هدف. با اعداد کوچک به‌جای شناسهٔ توکن‌ها حسی از max_length، stride و دسته‌ها بسازید.

فرض کنید «متن» همان اعداد 0 تا 11 است. هر سطر یک پنجرهٔ (ورودی، هدف) است؛ هدف همان ورودی است که یک گام به راست رفته.

stride برابر 1: هم‌پوشانی زیاد

max_length = 4, stride = 1
input [0 1 2 3]   target [1 2 3 4]
input [1 2 3 4]   target [2 3 4 5]
input [2 3 4 5]   target [3 4 5 6]
...
input [7 8 9 10]  target [8 9 10 11]    -> 8 windows

stride برابر 4: بدون هم‌پوشانی، بدون جاافتادگی

max_length = 4, stride = 4
input [0 1 2 3]   target [1 2 3 4]
input [4 5 6 7]   target [5 6 7 8]
                                       -> 2 windows  (the third would need target[12])

پنجرهٔ آخر حذف می‌شود چون هدفش از انتها بیرون می‌زند. به همین دلیل حلقه در len - max_length متوقف می‌شود.

چند پنجره؟

با n توکن: ceil((n - max_length) / stride). برای داستان، n = 5,145: با stride برابر 4، تعداد 1,286 پنجره؛ با stride برابر 1، تعداد 5,141.

دسته‌ها

batch_size = 2, drop_last = true, 5 windows w0..w4
batch 0: w0 w1
batch 1: w2 w3
(w4 dropped: a batch of 1 would be a different size)

with shuffle = true the window order is mixed first:  w3 w0 w4 w1 w2 ...

کدام تنظیم برای چه وقت؟

تنظیممقدار کوچکمقدار بزرگ
max_lengthارزان، زمینهٔ کمزمینهٔ بیشتر در هر نمونه، حافظهٔ بیشتر
strideنمونه‌های هم‌پوشان فراوان، خطر بیش‌برازشنمونهٔ کمتر، بدون تکرار
batch_sizeحافظهٔ کمتر، به‌روزرسانی پرنوفه‌تربه‌روزرسانی نرم‌تر، حافظهٔ بیشتر

امتحان کنید

  1. تعداد پنجره‌ها را برای n = 20, max_length = 5, stride = 3 پیش‌بینی کنید، سپس با کد خودتان بسنجید.
  2. همین لودر را با shuffle=true دو بار با یک بذر اجرا کنید، سپس با بذرهای متفاوت. چه تغییر می‌کند؟
پاسخ ۱ceil((20 - 5) / 3) = 5 پنجره، با شروع از 0، 3، 6، 9، 12.
