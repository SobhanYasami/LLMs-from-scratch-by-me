3.1-3.2: Why attention exists

Book section 3.1, 3.2

Aim. Understand the problem attention solves, and what the four attention variants of this chapter are.

The problem: a single summary is not enough

Translating a sentence word by word fails, because word order and grammar differ between languages. Before transformers, the standard fix was an encoder-decoder RNN. An RNN reads text one step at a time, updating a hidden state (its memory) at each step.

Encoderreads the whole input, squeezes it into one final hidden state
→
One hidden statethe only thing the decoder gets
→
Decoderwrites the translation word by word

The decoder cannot look back at the encoder's earlier states. Everything about a long sentence has to survive in that single vector, so context is lost over long distances.

The fix: let the decoder look back, selectively

In 2014 Bahdanau attention changed the decoder so that, at each output step, it can pick which input positions to read, giving some positions more attention weight than others. Three years later the transformer showed the RNN itself is not needed: use attention alone, applied by the sequence to itself.

Self-attention. Every position in a sequence looks at every position in the same sequence (including itself) to build a better representation of itself.

Check yourself

What is the bottleneck of an encoder-decoder RNN?The decoder only sees the encoder's final hidden state, so a long input has to be compressed into one vector.
What does "self" in self-attention mean?The attention is computed between positions of the same sequence, not between two different sequences.
Which variant is the one GPT uses?Causal multi-head attention (3.5 and 3.6 combined).
