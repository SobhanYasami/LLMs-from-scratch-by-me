Build an LLM from scratch

A tutorial and reference for the first two chapters of Build a Large Language Model (From Scratch). Chapter 1 builds the mental model. Chapter 2 turns it into code, written three times: Python, Go and Rust, with the same layout and the same output.

Aim. Understand what a GPT-style model is, and how text becomes the numbers it trains on, by reading small programs instead of a framework.

The map

Chapter 1What an LLM is, how it is trained, what a GPT looks like. No code.
→
Chapter 2Text → tokens → IDs → training pairs → vectors. All the code on this site.
→
Chapter 3+Attention, the GPT model, training. Not covered yet.

How to read this site

  • Read in order. Page titles carry the book's section numbers (1.1, 2.2, ...) so you can follow along with the PDF.
  • Every code block has Python / Go / Rust tabs. Your choice is remembered.
  • Each page has an Aim. Chapter 1 pages end with check yourself questions. Chapter 2 pages end with exercises.
  • The Reference page is a lookup table of every function in all three languages.

Run the code

LanguageCommand
Pythonpython-version/.venv/bin/python python-version/main.py
Gocd go-version && go run ./cmd
Rustcd rust-version && cargo run

All three print the same token IDs. Embedding values differ (each language draws its own random weights) but shapes match.
