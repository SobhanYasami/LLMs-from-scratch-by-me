Build an LLM from scratch

A living tutorial and reference for Build a Large Language Model (From Scratch). The goal is to cover the whole book, one chapter at a time, with the ideas explained in plain words and the code written in five languages side by side.

Aim. Understand how a GPT-style model works by reading small programs instead of a framework, and keep a reference you can come back to.

How each page works

  • Aim at the top says what you will understand by the end.
  • The page title carries the book's section numbers (2.2, 2.7-2.8, ...) so you can read along with the PDF.
  • Code blocks have tabs for Python, Go, Rust, C and Zig. They are the real source files from this repo, and your tab choice is remembered.
  • Chapter 1 pages end with check yourself questions; code chapters end with exercises. Pages marked extra go beyond the book.

Run the code

LanguageCommand
Pythonpython-version/.venv/bin/python python-version/main.py
Gocd go-version && go run ./cmd
Rustcd rust-version && cargo run
Ccd C-version && make run
Zigcd Zig-version && zig build run

All five print identical output for the tokenizers, BPE and data sampling. Embedding values differ (each language draws its own random weights) but shapes match.

Why five languages?

Seeing the same idea in a high-level and in a low-level language shows what is essential and what is language plumbing. Python hides memory and uses a tensor library; C and Zig make every allocation visible; Go and Rust sit in between. When a concept is hard to see in one, read it in another.
