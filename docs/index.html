Build an LLM from scratch

A learning repo and living reference. One idea per step, written three times: Python, Go and Rust, with the same layout and the same output.

Aim. Understand how text becomes the numbers a GPT-style model trains on, by reading small programs instead of a framework. Follows Build a Large Language Model (From Scratch) by Sebastian Raschka, chapter 2.

The pipeline

raw text
  -> split into tokens        (step 1)
  -> token -> ID             (step 2)
  -> encode / decode          (step 3)
  -> windows of (input, target)  (step 4)
  -> vectors + positions      (step 5)   <- what the model finally reads

How to read this site

  • Go through the steps in order. Each uses the one before it.
  • Every code block has Python / Go / Rust tabs. Your choice is remembered.
  • Each step has an Aim, the code, sample output, and exercises.
  • The Reference page is a lookup table of every function in all three languages.
