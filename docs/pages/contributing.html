The site is built to grow. A new page is one file; a new chapter is a few lines of data. Everything else (navigation, roadmap, progress, chapter pages) is generated.

The pieces

WhereWhat it holds
docs/pages/*.htmlOne file per page: a front-matter block, then HTML.
docs/syllabus.pyThe whole book (chapters and sections), the languages, and which source files each code tab shows.
docs/pages/fa/*.htmlPersian translations, one file per English page.
docs/i18n.pyInterface strings and Persian chapter names.
docs/build.pyThe generator. Rarely needs editing.
docs/style.css, site.jsLook and the language tabs.

Build with python3 docs/build.py, then commit the generated HTML along with your changes.

Add a page

  1. Create docs/pages/ch03-3-self-attention.html starting with: 
    ---
title: 3.3: A simple self-attention mechanism
nav: 3.3 Self-attention
chapter: 3
section: 3.3
order: 30
code: attention_simple
---
<div class="aim"><b>Aim.</b> ...</div>
...
{{code}}
  2. chapter is the chapter number (or A for appendices); section lists the book sections the page covers (2.7, 2.8 for two); order sorts pages inside a chapter.
  3. Put {{code}} where the Python / Go / Rust / C / Zig tabs should go, and define attention_simple in CODE inside syllabus.py (see below).
  4. Run the build. The section flips from planned to ready on the roadmap by itself.

Add an extra

An extra goes beyond the book. Use the same front matter, add extra: true, and leave section empty. It appears under its chapter, marked with a plus, and on the chapter page.

Add code for a chapter

  1. Write the same module in every language folder, using the same names (see the layout on the reference page). Match outputs across languages.
  2. In docs/syllabus.py add an entry to CODE, listing the files each language tab shows, e.g. "attention_simple": {"python": ["attention/simple.py"], "go": [...], ...}. A language you leave out shows "Not implemented yet".
  3. Set the chapter's langs in CHAPTERS to the languages that now implement it. The language matrix on the roadmap updates.

Add a language

  1. Create Lang-version/ with the same layout and a README.
  2. Add a line to LANGS in docs/syllabus.py, plus a highlight.js grammar in build.py if the language needs one.
  3. Add its files to each CODE entry and include it in the chapters' langs as it catches up.

Add a chapter

Chapters 3 to 7 and the appendices are already outlined in syllabus.py as planned. To refine one, edit its sections list; to write it, add pages as above.

Add a translation

The site is built in English and Persian. A translated page is a file with the same name in docs/pages/fa/. Copy the English page, translate the front matter (title, nav) and the text, and leave chapter, section, order, code and extra as they are (they are taken from the English page anyway). Keep code blocks, output blocks and {{code}} unchanged.

  • Pages without a Persian file show the English text inside the Persian site, with a notice and an EN mark in the navigation. So a half-translated site always works.
  • Chapter titles, summaries and section names come from docs/i18n.py (FA_CHAPTERS); buttons and labels are in UI there. A new language is one more entry in LANGS_UI and UI.

Writing guidelines

  • Start every page with an Aim: what the reader will understand.
  • Explain in plain words first, then show code. Keep the book's section numbers in titles.
  • Real numbers from real runs beat invented ones. If you paste output, run the code first.
  • Own words only. Do not copy the book's text or figures.
  • End with exercises or "check yourself" questions, and hide answers in a <details class="qa"> block.
