1.6-1.7: GPT architecture and the roadmap

Book section 1.6, 1.7

Aim. See why next-word prediction needs no labels, why GPT is just a decoder, and where this book is heading.

Self-supervised learning

Take any text. The input is the words so far; the label is simply the next word, which the text already contains. The data labels itself, so any pile of text can train the model. This is why chapter 2 builds exactly one thing: pairs of (input tokens, same tokens shifted by one).

text:    The cat sat on the mat
input:   The cat sat on
target:      cat sat on the     (shifted by one)

GPT is a decoder only

  • GPT = Generative Pretrained Transformer, from OpenAI (2018). ChatGPT's first model was GPT-3 finetuned on instructions.
  • It uses only the decoder: no encoder, strictly left to right.
  • It is autoregressive: each new word is picked using the words before it, and then becomes part of the next input.
  • Scale differs hugely: the original transformer stacked 6 blocks; GPT-3 has 96 layers and 175 billion parameters. Modern models such as Llama still use the same core ideas.

Emergent behaviour

GPT is only trained to predict the next word, yet it also translates, classifies and summarises. Nobody taught it those tasks explicitly. Abilities that appear without being trained for are called emergent behaviour, a result of scale and diverse data.
