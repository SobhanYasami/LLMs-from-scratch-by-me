Aim. See with real numbers why deep networks need shortcut connections: without them the first layers hardly learn, with them every layer does.

The idea: add the input back

Plain layer

x = layer(x)
The output replaces the input. Everything the layer does must be correct, and the gradient must pass through it.

With a shortcut

x = x + layer(x)
The layer only learns a correction to its input. The input also has a direct path forward, and the gradient a direct path back.

A shortcut, also called a skip or residual connection, was invented for very deep image networks. GPT uses it twice in every transformer block (next page).

Why gradients vanish

Training adjusts each weight by its gradient: how much the loss changes when that weight changes. The gradient for an early layer is computed by passing it backwards through every later layer, multiplying a number at each step. If those numbers are mostly smaller than 1, the product shrinks layer by layer: the vanishing gradient problem. Early layers then get almost no learning signal.

Watch it happen

The demo builds a network with five layers (each Linear followed by GELU, sizes 3, 3, 3, 3, 3, then 1), feeds it [1, 0, -1] with target 0, and prints the mean absolute gradient of each layer's weights. The weights are the book's, so the numbers match the book.

  • Without shortcuts the gradient falls by a factor of about 25 from the last layer to the first (0.00505 to 0.0002). The first layer learns 25 times slower than the last.
  • With shortcuts all layers sit between 0.2 and 0.3, and only the final layer is larger. Nothing vanishes. The last layer has no shortcut (it goes from 3 numbers to 1, so there is nothing of the same shape to add), which is why it stays largest.

Where do these numbers come from?

Python asks torch's autograd for them (loss.backward()). Go, Rust, C and Zig have no autograd, so each program does the backward pass by hand: start at the loss, and for each layer from the last to the first apply the chain rule (GELU's slope, then the weights). With a shortcut the gradient flowing down also gets the gradient from the skip path added. About 40 lines, and it reproduces torch's numbers to six decimals, which is a nice check that both are right.

The two-line difference in the code is just this: x = x + layer_output if the shapes match and use_shortcut is on, otherwise x = layer_output.
