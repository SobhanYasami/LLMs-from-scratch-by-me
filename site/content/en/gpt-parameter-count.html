Aim. Derive the 163,009,536 parameters of the model yourself from the configuration, and turn it into a formula you can reuse for any size.

A parameter is one learned number. Count them tensor by tensor. Let V be the vocabulary size, C the context length, D the embedding size and N the number of blocks.

One transformer block

PieceShapeParameters (D = 768)
W_query, W_key, W_value3 x (D x D)3 x 589,824 = 1,769,472
output projection weightD x D589,824
output projection biasD768
attention total: 4 D2 + D2,360,064
feed forward, expand: weight + biasD x 4D, 4D2,359,296 + 3,072
feed forward, shrink: weight + bias4D x D, D2,359,296 + 768
feed forward total: 8 D2 + 5 D4,722,432
two layer norms: scale + shift each4 x D3,072
one block: 12 D2 + 10 D7,085,568

The query, key and value projections have no bias (the qkv_bias = False setting), but the output projection does.

The whole model

total = V*D                  token embedding
      + C*D                  position embedding
      + N * (12*D^2 + 10*D)  the blocks
      + 2*D                  final layer norm
      + D*V                  output head

GPT-2 small: 38,597,376 + 786,432 + 12 x 7,085,568 + 1,536 + 38,597,376
           = 163,009,536

That is the function parameter_count in the model file, in every language. The program checks it against the model it actually builds, and a unit test pins the book's number.

Which parts are big?

PartParametersShare
2 x vocabulary matrices (embedding + head)77,194,75247%
12 blocks85,026,81652%
position embedding + final norm787,9680.5%

For a small model the two vocabulary matrices are about as heavy as all twelve blocks together. As models grow, the blocks (growing with D2 and N) take over: in GPT-2 XL the vocabulary matrices are only about 10% of the total.

Try it

  1. Use the formula for GPT-2 medium (D = 1024, N = 24, 16 heads). Do you get 406,212,608?
  2. Do the number of heads matter for the parameter count? Why or why not?
  3. Subtract D x V to get the weight-tied count. Which of the four sizes comes closest to its marketing name (124M, 355M, 774M, 1558M)?
Answers1) 50,257x1024 + 1024x1024 + 24 x (12x10242 + 10x1024) + 2048 + 1024x50,257 = 406,212,608. 2) No: heads only split the D columns into groups, the matrices keep the same total size. 3) All four match when weight-tied: 124.4M, 354.7M, 773.9M, 1,557.4M.
