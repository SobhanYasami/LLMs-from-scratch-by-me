Aim. Follow the AdamW update for a single weight over a few steps, and see the surprising thing it does with the size of the gradient.

One weight, starting at 1.0, learning rate 0.001, weight decay 0.1, the usual b1 = 0.9, b2 = 0.999, and a gradient that stays at 0.1 for three steps and then flips to -0.1.

Reading the table

  • m is a running average of the gradient: m = 0.9 m + 0.1 g. It remembers the direction.
  • v is a running average of the squared gradient: v = 0.999 v + 0.001 g2. It remembers how big the gradients are.
  • Bias correction. Both start at 0, so at first they are too small. Dividing by 1 - bt fixes that: m_hat and v_hat are 0.1 and 0.01, the true values, from step 1.
  • The update is lr x m_hat / (sqrt(v_hat) + eps) = 0.001 x 0.1 / 0.1 = 0.001. Plus weight decay: first the weight shrinks by the factor 1 - lr x wd = 0.9999. Together: 1.0 x 0.9999 - 0.001 = 0.9989.
  • Step 4: the gradient flips to -0.1. The average m (the direction) has not turned yet, it has only shrunk to 0.0418 after correction; the step gets smaller, and next steps will reverse. This is momentum: one noisy gradient does not throw the weight around.

The surprise: the size of the gradient hardly matters

Redo steps 1 to 3 with a gradient of 100 instead of 0.1: the weight goes 0.998900, 0.997800, 0.996700, exactly the same. Why? The update divides m_hat by sqrt(v_hat), and both scale with g, so the ratio is about 1 whatever g is. Adam moves each weight by roughly the learning rate per step, in the direction of its steady gradient. That is why one learning rate works for weights whose gradients differ by factors of a thousand, for instance the layers that suffer from the vanishing gradient of 4.4. Plain gradient descent would move them a thousand times apart.

Where it lives

The arithmetic is the file adamw.* (about 25 lines): the update above for every number of every tensor, with the same order of operations as torch.optim.AdamW so the results agree to the last digits.

Try it

  1. What would the weight be after step 1 with weight decay 0?
  2. If the gradient is exactly 0 for a weight for many steps, what does AdamW still do to it?
Answers1) 1.0 - 0.001 = 0.999. 2) Weight decay keeps shrinking it by 0.01% per step (at lr 0.001, wd 0.1), and the old momentum m carries it on for a while, fading by 10% each step.
