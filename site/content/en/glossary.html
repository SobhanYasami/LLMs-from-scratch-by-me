Terms used in the tutorial, with the chapter where each first matters. Add new terms as new chapters land.

TermMeaningSee
TokenThe unit of text a model reads: a word, part of a word, or a punctuation mark.2.2
Token IDThe integer a token is mapped to by the vocabulary.2.3
VocabularyThe table token ↔ ID. Its size is the number of distinct tokens.2.3
Special tokenA token added on purpose, such as <|endoftext|> or <|unk|>.2.4
BPE (byte pair encoding)A sub-word tokenizer built by repeatedly merging the most frequent neighbouring pairs.2.5
Rank (BPE)The merge order of a token. Lower rank means merged earlier, more common.extra
Context length / max_lengthHow many tokens the model sees at once.2.6
StrideHow far the sliding window moves between training examples.2.6
BatchA group of examples processed together.2.6
EmbeddingA vector that stands for a token (or position). Learned during training.2.7
Positional embeddingA vector added to say where in the sequence a token sits.2.8
Next-token predictionThe training task: given the tokens so far, predict the next one.1.6
Self-supervised learningLearning where the labels come from the data itself (the next word).1.6
Pretraining / finetuningBroad training on raw text, then adaptation on labelled data.1.3
TransformerThe architecture built on attention; encoder, decoder, or both.1.4
Zero-shot / few-shotDoing a task with no examples, or a few examples in the prompt.1.4
AutoregressiveEach output is fed back as input for the next prediction.1.6
Emergent behaviourA skill that shows up at scale without being trained for explicitly.1.6
AttentionA way for each position to weigh and mix information from other positions.3.1
Self-attentionAttention between positions of the same sequence.3.2
Context vectorA token's embedding enriched with information from the other tokens.3.3
Attention scoreRaw similarity (dot product) between a query and a key.3.3
Attention weightSoftmax of the scores: positive, rows sum to 1. Computed fresh for each input.3.3
SoftmaxTurns a list of numbers into positive weights that sum to 1.3.3
Query / key / valueThree projections of each token: what it looks for, what it offers, what it hands over.3.4
Weight parametersThe learned matrices (W_query, W_key, W_value, ...). Not the same as attention weights.3.4
Scaled dot-product attentionSelf-attention with scores divided by sqrt(d_k).extra
Causal (masked) attentionAttention where a token cannot see later tokens.3.5
DropoutRandomly zeroing values during training, scaling the rest, to reduce overfitting.3.5
Attention headOne independent query/key/value attention computation.3.6
Multi-head attentionSeveral heads in parallel, concatenated and mixed by an output projection.3.6
Layer normalizationRescaling each token's vector to mean 0 and variance 1 (then a learned scale and shift).4.2
epsA tiny constant added to the variance so layer norm never divides by zero.4.2
GELUA smooth activation function, like ReLU but with a gentle curve near zero. Used in GPT.4.3
Feed forward networkPer-token block: expand 4x, GELU, shrink back. No mixing between tokens.4.3
Shortcut (residual) connectionAdding a layer's input to its output, so gradients keep a short path back.4.4
Vanishing gradientGradients shrinking as they travel back through many layers, so early layers barely learn.4.4
Transformer blockLayer norm, attention, shortcut, layer norm, feed forward, shortcut. Repeated N times in a GPT.4.5
Pre-LayerNormNormalizing the input of each sub-layer instead of its output. The layout GPT-2 uses.4.5
LogitsThe model's raw scores for the next token, one per vocabulary entry.4.1
Weight tyingReusing the token embedding matrix as the output head, so its parameters count once.4.6
Greedy decodingAlways picking the highest-scoring next token.4.7
KV cacheRemembering the keys and values of past tokens so each new token costs one step, not a full re-run.4.7
Cross entropy lossMinus the average log of the probability the model gave to the correct next token. 0 is perfect; ln(vocabulary) is a uniform guess.5.1
Perplexityexp(loss): the effective number of tokens the model is undecided between.5.1
Validation setText held back from training to check that the model has learned language and not just memorised.5.1
EpochOne pass over all the training batches.5.2
GradientFor one weight: how much the loss changes if that weight changes a little.5.2
BackpropagationComputing every gradient by walking the layers backwards with the chain rule.extra
AdamWThe optimizer: each weight moves by roughly the learning rate in the direction of its steady gradient, with weight decay.extra
OverfittingTraining loss keeps falling while validation loss stalls: the model memorises its training text.5.2
TemperatureA divisor for the logits before softmax: below 1 sharpens, above 1 flattens the distribution.5.3
Top-k samplingKeep only the k highest logits (the rest become -inf) before drawing the next token.5.3
CheckpointA file with a model's settings and weights (and optionally the optimizer state).5.4
safetensorsA plain file format for tensors: header length, JSON header, raw numbers. How OpenAI's GPT-2 weights are shared.5.5
