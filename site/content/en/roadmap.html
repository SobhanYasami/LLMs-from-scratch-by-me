The whole project on one page: what we are building, in what order, and where every piece sits in the finished model. Every box is a link. Boxes whose page is not written yet are dashed.

What we are building

A GPT-style language model, from an empty file to something that follows instructions. The book builds it in three stages, and each stage uses only what the stage before it produced.

written, with code in five languages planned

Read it top to bottom. Stage 1 produces a model that has the right shape but knows nothing. Stage 2 gives it language. Stage 3 gives that language a job.

Inside the model

The same GPT, drawn as it is built, from the input text at the top to the next token at the bottom. The grey tags are book sections. The two boxes on the side show when each part is trained.

  • Chapter 2 builds the front door: everything that turns text into vectors the model can read.
  • Chapter 3 builds the one idea that makes it a transformer: attention, the only place tokens look at each other.
  • Chapter 4 wraps attention in a repeatable block and stacks it into the full model (the box marked × N is repeated 12 times in GPT-2 small).
  • Chapters 5 to 7 do not change this picture. They change the numbers inside the boxes: pretraining finds them, finetuning adjusts them.

How the project grows

  1. Cover the book. One chapter at a time, in the book's order. Concepts first, then code in every language.
  2. Extras. Deeper dives that the book only hints at: worked examples, comparisons, bonus topics. They live next to their chapter.
  3. More languages. Adding a language means filling its folder with the same modules and one column in the tables.
