Aim. Run all of chapter 4 in one go, and check your output against the expected text, in any of the five languages.

Run it

LanguageCommand
Pythonpython-version/.venv/bin/python python-version/main.py ch04
Gocd go-version && go run ./cmd ch04
Rustcd rust-version && cargo run -- ch04
Ccd C-version && make run ARGS=ch04
Zigcd Zig-version && zig build run -- ch04

All five print the same text, character for character, and so does the 124M version (ch04-124m). Without an argument each program runs every chapter.

What to compare with the book

  • 4.2, 4.3 and 4.4 reproduce the book's numbers: the layer-norm means and variances, the GELU curve, and the gradient table (the 4.4 weights are the book's torch.manual_seed(123) ones, written out in the code).
  • 4.6 reproduces the exact counts: 163,009,536 parameters, 124,412,160 with weight tying, 621.83 MB.
  • 4.1, 4.5 and 4.7 use random weights from this repo's shared generator, so they differ from the book's torch output but agree across the five languages. The generated words are gibberish by design.
