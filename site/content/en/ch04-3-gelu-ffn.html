Aim. Meet GELU, the smooth activation GPT uses instead of ReLU, and the feed forward block that processes every token on its own.

GELU in one picture of numbers

A neural layer is a matrix multiply followed by a non-linear activation function; without it, a stack of layers collapses into one big matrix multiply. ReLU is the classic: max(0, x). GPT uses GELU, which behaves like ReLU for large inputs but is smooth near zero and lets a little of negative inputs through.

x   : [-3.0000, -2.0000, -1.0000, 0.0000, 1.0000, 2.0000, 3.0000]
GELU: [-0.0036, -0.0454, -0.1588, 0.0000, 0.8412, 1.9546, 2.9964]
ReLU: [0.0000, 0.0000, 0.0000, 0.0000, 1.0000, 2.0000, 3.0000]
  • For big positive x, GELU(x) is almost x (2.9964 for 3).
  • For big negative x, it is almost 0, but not exactly: -0.0454 for -2, -0.1588 for -1. ReLU gives a flat 0 there.
  • There is no sharp corner at 0, so the slope changes gradually. That makes optimization a little easier, and a unit that is "off" can still learn.

The exact definition is x * Phi(x), where Phi is the probability that a standard bell-curve number is below x. Computing Phi is slow, so GPT-2 was trained with this cheap approximation, and so do we:

GELU(x) = 0.5 * x * (1 + tanh( sqrt(2/pi) * (x + 0.044715 * x^3) ))

The feed forward block

Every transformer block has two parts. Attention (chapter 3) mixes information between tokens. The feed forward network then works on each token separately, the same small network for every position.

[T, D]input
→
Linear D → 4Dexpand
→
GELU
→
Linear 4D → Dshrink
→
[T, D]output
  • The first layer widens each token's vector four times (768 to 3,072 in GPT-2 small), giving the model a roomier space to compute in.
  • GELU adds the non-linearity.
  • The second layer shrinks it back, so the output has the same shape as the input and the block can be stacked.
feed forward: input (2, 3, 32) -> output (2, 3, 32) (hidden layer is 4 x 32 = 128 wide)
The feed forward network holds about two thirds of the parameters of a block. For GPT-2 small: 4,722,432 parameters in the feed forward part against 2,360,064 in attention (exercise 4.1 on page 4.6).

A Linear layer in this repo

A linear layer computes x @ W + b. We store W as [in, out], so the same matmul from chapter 3 does the work. PyTorch's nn.Linear stores the transpose [out, in]; that is the only difference, and the Python model handles it when it copies weights.

Exercises

  1. Compute GELU(0.5) with the formula by hand, then check it with the code. Is it above or below 0.5?
  2. Where does GELU differ from ReLU the most: near 0, or far from 0?
  3. How many parameters does the feed forward block have for D = 32? (Count weights and biases of both layers.)
Answers1) About 0.3457, below 0.5: GELU shrinks small positive numbers a little. 2) Near 0, where ReLU has its corner; far from 0 they agree. 3) 32x128 + 128 + 128x32 + 32 = 8,352.

Check yourself

Why a non-linear activation at all?Without it, stacked linear layers are equivalent to a single linear layer, so depth would add nothing.
What does the feed forward block do to a token's vector size?Expands it 4x, applies GELU, then shrinks it back, so input and output have the same size.
Does the feed forward block mix information between tokens?No. Each token is processed alone; attention does the mixing.
