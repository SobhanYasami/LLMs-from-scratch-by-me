Aim. Run all of chapter 5 in one go, and check your output against the expected text, in any of the five languages.

Run it

LanguageTraining demo (about 10 to 40 s)OpenAI's GPT-2 (5.5, needs the download)
Pythonpython-version/.venv/bin/python python-version/main.py ch05... main.py ch05-gpt2
Gocd go-version && go run ./cmd ch05go run ./cmd ch05-gpt2
Rustcd rust-version && cargo run --release -- ch05cargo run --release -- ch05-gpt2
Ccd C-version && make run ARGS=ch05make run ARGS=ch05-gpt2
Zigcd Zig-version && zig build run -Doptimize=ReleaseFast -- ch05zig build run -Doptimize=ReleaseFast -- ch05-gpt2

Run from inside the language's folder, as for the other chapters. Build in release mode (Rust, Zig): training is a lot of arithmetic. Without an argument each program runs every chapter, including this one.

What to compare

  • Go, Rust, C and Zig print the same text, character for character. They run the same arithmetic in the same order. Their saved models are even byte-identical.
  • Python (torch) is the same up to step ~100, then differs in the last digits of the late training lines and therefore in the generated samples (the 5.2 and 5.3 sections after the first epoch, and 5.4's "3 more steps"). Everything that does not depend on late training is identical: 5.1, the 9-word demos of 5.3, 5.5.
  • All five print exactly the same 5.5 output (generated text and loss), proof that the weights were loaded correctly everywhere.
