Aim. Put layer norm, attention, the feed forward block and shortcuts together into the one block a GPT repeats.

The transformer block is the heart of the model. It is two sub-layers in a row, and both follow the same recipe: normalize, run the layer, add the input back.

x[T, D]
→
layer norm 1
→
multi-head attentionfrom chapter 3
→
+ xshortcut
→
layer norm 2
→
feed forwardfrom 4.3
→
+ inputshortcut
x = x + attention(norm1(x))      <- tokens look at each other
x = x + feed_forward(norm2(x))   <- each token is processed on its own

Division of labour

  • Attention relates each token to the earlier ones and builds a context vector (chapter 3). This is the only place where tokens exchange information.
  • Feed forward then transforms each token's vector independently, giving the model capacity to compute with what attention gathered.
  • Shortcuts keep gradients healthy (4.4); layer norm keeps the numbers in range (4.2).

Shape in, shape out

input shape: (2, 4, 32)  output shape: (2, 4, 32)
input[0][0], first 4 numbers: [0.0038, 0.0152, 0.0213, -0.0097]
output[0][0], first 4 numbers: [0.0137, 0.0182, 0.0086, -0.0207]

The shape does not change, but the content does: each output vector now mixes in information from the tokens before it. That is the whole point, and it is why 12 blocks in a row can refine the representation step by step.

Pre-LayerNorm. We normalize before each sub-layer. The original 2017 transformer normalized after (post-LayerNorm), which tends to train less smoothly in deep stacks. GPT-2 and nearly every LLM since use the pre-norm layout shown here.
Dropout. The book also applies dropout after each sub-layer (only while training). The Python version has it as an nn.Dropout that model.eval() switches off. The other four languages implement the inference path only, so they leave it out; the output is identical when dropout is off. Training arrives in chapter 5.

It reuses chapter 3 unchanged

MultiHeadAttention is the exact class from chapter 3, built with d_in = d_out = emb_dim and weights from the random generator. Nothing new was needed, which is a good sign for the design.

Check yourself

Which part of the block lets tokens interact?Multi-head attention. The feed forward network treats each token separately.
Why does the block keep the shape [T, D]?So that blocks can be stacked, and so shortcuts can add the input to the output.
What is "pre-LayerNorm"?Normalizing the input of each sub-layer (before attention and before the feed forward), not its output.
