هدف. با GELU آشنا شوید، فعال‌ساز نرمی که GPT به‌جای ReLU به کار می‌برد، و با بلوک پیش‌خور که هر توکن را جداگانه پردازش می‌کند.

GELU در یک تصویر از عددها

یک لایهٔ عصبی ضرب ماتریسی است و پس از آن یک تابع فعال‌ساز غیرخطی؛ بدون آن، پشتهٔ لایه‌ها به یک ضرب ماتریسی بزرگ فرو می‌ریزد. ReLU نمونهٔ کلاسیک است: max(0, x). GPT از GELU استفاده می‌کند که برای ورودی‌های بزرگ مانند ReLU رفتار می‌کند اما نزدیک صفر نرم است و کمی از ورودی‌های منفی را رد می‌کند.

x   : [-3.0000, -2.0000, -1.0000, 0.0000, 1.0000, 2.0000, 3.0000]
GELU: [-0.0036, -0.0454, -0.1588, 0.0000, 0.8412, 1.9546, 2.9964]
ReLU: [0.0000, 0.0000, 0.0000, 0.0000, 1.0000, 2.0000, 3.0000]
  • برای x مثبت بزرگ، GELU(x) تقریباً خود x است (برای 3 برابر 2.9964).
  • برای x منفی بزرگ تقریباً 0 است اما نه دقیقاً: برای ورودی -2 مقدار -0.0454 و برای ورودی -1 مقدار -0.1588. ReLU آنجا 0 ثابت می‌دهد.
  • در 0 گوشهٔ تیزی نیست، پس شیب تدریجاً عوض می‌شود. این بهینه‌سازی را کمی آسان‌تر می‌کند، و واحدی که «خاموش» است هنوز می‌تواند یاد بگیرد.

تعریف دقیق x * Phi(x) است، که Phi احتمال این است که یک عدد زنگوله‌ای استاندارد زیر x باشد. محاسبهٔ Phi کند است، پس GPT-2 با این تقریب ارزان آموزش دید و ما هم چنین می‌کنیم:

GELU(x) = 0.5 * x * (1 + tanh( sqrt(2/pi) * (x + 0.044715 * x^3) ))

بلوک پیش‌خور

هر بلوک ترنسفورمر دو بخش دارد. توجه (فصل ۳) اطلاعات را میان توکن‌ها می‌آمیزد. سپس شبکهٔ پیش‌خور روی هر توکن جداگانه کار می‌کند، همان شبکهٔ کوچک برای هر جایگاه.

  • لایهٔ اول بردار هر توکن را چهار برابر پهن می‌کند (در GPT-2 کوچک از 768 به 3,072) و به مدل فضای جادارتری برای محاسبه می‌دهد.
  • GELU غیرخطی بودن را اضافه می‌کند.
  • لایهٔ دوم آن را به اندازهٔ اول برمی‌گرداند، پس خروجی شکلی برابر ورودی دارد و بلوک قابل چیدن روی هم است.
feed forward: input (2, 3, 32) -> output (2, 3, 32) (hidden layer is 4 x 32 = 128 wide)
شبکهٔ پیش‌خور حدود دو سوم پارامترهای یک بلوک را دارد. برای GPT-2 کوچک: 4,722,432 پارامتر در بخش پیش‌خور در برابر 2,360,064 در توجه (تمرین 4.1 در صفحهٔ 4.6).

یک لایهٔ Linear در این مخزن

لایهٔ خطی x @ W + b را حساب می‌کند. W را به شکل [in, out] ذخیره می‌کنیم، پس همان matmul فصل ۳ کار را انجام می‌دهد. nn.Linear در PyTorch ترانهادهٔ آن یعنی [out, in] را نگه می‌دارد؛ تنها تفاوت همین است و مدل Python هنگام کپی وزن‌ها آن را مدیریت می‌کند.

کد

همان فایل 4.2. اکنون gelu، Linear و FeedForward را بخوانید.

تمرین‌ها

  1. GELU(0.5) را با فرمول دستی حساب کنید، سپس با کد بسنجید. بالای 0.5 است یا پایین آن؟
  2. GELU بیشتر کجا با ReLU فرق دارد: نزدیک 0 یا دور از 0؟
  3. بلوک پیش‌خور برای D = 32 چند پارامتر دارد؟ (وزن‌ها و بایاس‌های هر دو لایه را بشمارید.)
پاسخ‌ها۱) حدود 0.3457، پایین 0.5: GELU عددهای مثبت کوچک را اندکی کوچک‌تر می‌کند. ۲) نزدیک 0، جایی که ReLU گوشه دارد؛ دور از 0 یکی‌اند. ۳) 32x128 + 128 + 128x32 + 32 = 8,352.

خودآزمایی

چرا اصلاً فعال‌ساز غیرخطی لازم است؟بدون آن، لایه‌های خطی روی هم برابر یک لایهٔ خطی تنها هستند، پس عمق چیزی اضافه نمی‌کند.
بلوک پیش‌خور با اندازهٔ بردار توکن چه می‌کند؟چهار برابرش می‌کند، GELU می‌زند، سپس برمی‌گرداند، پس ورودی و خروجی هم‌اندازه‌اند.
آیا بلوک پیش‌خور میان توکن‌ها اطلاعات می‌آمیزد؟نه. هر توکن تنها پردازش می‌شود؛ آمیختن را توجه انجام می‌دهد.
