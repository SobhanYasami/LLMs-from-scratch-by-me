هدف. 163,009,536 پارامتر مدل را خودتان از روی پیکربندی به دست آورید و آن را به فرمولی برای هر اندازه تبدیل کنید.

پارامتر یک عدد یادگرفته‌شده است. تانسور به تانسور بشمارید. فرض کنید V اندازهٔ واژگان، C طول زمینه، D اندازهٔ امبدینگ و N تعداد بلوک‌هاست.

تصویرهای query، key و value بایاس ندارند (تنظیم qkv_bias = False)، اما تصویر خروجی دارد.

کل مدل

total = V*D                  token embedding
      + C*D                  position embedding
      + N * (12*D^2 + 10*D)  the blocks
      + 2*D                  final layer norm
      + D*V                  output head

GPT-2 small: 38,597,376 + 786,432 + 12 x 7,085,568 + 1,536 + 38,597,376
           = 163,009,536

این همان تابع parameter_count در فایل مدل، در هر زبان است. برنامه آن را با مدلی که واقعاً می‌سازد می‌سنجد و یک آزمون واحد عدد کتاب را ثابت نگه می‌دارد.

در مدل کوچک دو ماتریس واژگان تقریباً به‌اندازهٔ هر دوازده بلوک سنگین‌اند. با بزرگ شدن مدل، بلوک‌ها (که با D2 و N رشد می‌کنند) غالب می‌شوند: در GPT-2 XL ماتریس‌های واژگان فقط حدود ۱۰٪ مجموع‌اند.
